# remote-database-script

# How to run a script on a remote database

# This script is used to run a SQL script on a remote database using SSH and MySQL client.

# Use the following command to run the script:

# 1. Change to the directory where the script is located.

cd /path/to/your/script

# 2. Activate virtual environment.

source venv/bin/activate

# 3. Run the script with the following command:

python3 main.py
